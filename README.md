# 签字页项目基础配置模块

当前阶段开发变量管理和模板管理，用于维护后续模板绑定、项目数据录入和生成校验会使用的基础配置。

## 运行

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`，默认进入模板管理。

- 模板管理：`http://localhost:5173/templates.html`
- 变量管理：`http://localhost:5173/variables.html`
- 左侧菜单固定为“模板管理”在“变量管理”上方。

## 变量管理

- 变量列表：展示变量名、变量值、变量类型、更新时间。
- 新增变量：变量值作为唯一 ID，不允许重复。
- 编辑变量：支持修改变量名、类型、描述、状态。
- 删除变量：从变量列表移除，并写入审计日志。
- 变量详情：展示基础字段和变更日志。
- 类型规则：单一变量表示每个项目只录入一个值；枚举变量表示项目录入时可录入多条，用于生成多份签字页。

## 模板管理

- 模板列表：展示模板名称、数字模板 id、导入状态、更新时间。
- 新增模板：模板 id 根据时间戳生成数字 id。
- 编辑模板：支持修改模板名称、模板详情、状态和预览文本。
- 删除模板：从模板列表移除，并写入审计日志。
- 导入模板：支持 `.doc` / `.docx` 文件，原始文件保存在本地，便于后续按原始格式生成签字页。
- 模板预览：`.docx` 会提取正文、段落、表格、对齐、字体大小、颜色、加粗、斜体、下划线等 Word-like HTML 格式用于本地可编辑预览；`.doc` 保留原始文件，预览文本可手工粘贴。
- AI 提取变量：使用云端 Agnes 大模型接口，并提供可编辑提示词；接口失败或输出非法 JSON 不会覆盖正式提取结果。
- 提示词入参：后端会把用户提示词、系统已有变量 JSON、模板内容 JSON 化组装后发送给模型，并明确要求参考已存在的变量、参考模板文案，输出替换变量后的全部模板文案。
- AI 输出格式：要求返回完整报告模板正文，正文中穿插 `{{变量值}}`；系统按 `{{变量值}}` 去重生成提取变量。
- 变量对齐：AI 提取结果会参考变量管理中的已有变量，能匹配的变量直接对齐，未匹配的变量提示先创建。
- 预览高亮与还原：AI 成功后预览正文会替换为带颜色的 `{{变量值}}`，可还原到上一次提取前的预览和变量列表。

## 本地数据

运行数据保存在 `workspace/data/`：

- `variables.json`：变量列表及每个变量自己的变更日志。
- `templates.json`：模板列表、导入文件信息、预览文本、AI 提取变量和变更日志。
- `templates/{templateId}/`：模板原始 `.doc` / `.docx` 文件。
- `template-prompts.json`：模板变量提取提示词。
- `audit.ndjson`：变量新增、更新、删除的审计记录。
