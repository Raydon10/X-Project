# 签字页项目工作台

本地演示 MVP：一个账号在项目负责人、助理律师、审核人、模板管理员四种角色之间直接切换，完成模板变量识别、Excel 导入、DOCX 生成、审核和 ZIP 导出。

## 运行

执行：

    npm install
    npm run dev

浏览器打开 http://localhost:5173。

## 演示材料

- fixtures/签字页模板样例.docx
- fixtures/签字页导入样例.xlsx：含一条缺失公司名称的异常数据，适合演示预检。

## 推荐演示顺序

1. 切换“模板管理员”，运行 Codex 变量识别并确认建议。
2. 切换“助理律师”，上传 Excel，展示异常；使用合法行确认导入。
3. 切换“项目负责人”，发起批量 DOCX 生成并提交审核。
4. 切换“审核人”，审核通过；切回负责人下载 ZIP。
5. 在审计记录中查看每次操作对应的角色。

Codex CLI 不可用时，系统保留从预置模板占位符读取的确定性建议，不会写入未确认的变量。
